
# CUSTOMER SUPPORT SYSTEM

## 1. Giới thiệu
Hệ thống hỗ trợ yêu cầu khách hàng.

## 2. Công nghệ sử dụng
- C#
- .NET 10
- ASP.NET Core Minimal API
- RabbitMQ
- SignalR
- SQL Server
- Docker

## 3. Cấu trúc dự án
- Support.API: Tiếp nhận và quản lý yêu cầu.
- Assignment.Worker: Phân loại và phân công yêu cầu.
- Notification.Service: Gửi thông báo thời gian thực.
- Support.Client: Ứng dụng khách hàng.
- Support.Shared: Chia sẻ dữ liệu và sự kiện.

## 4. Tiến độ
- Tuần 1: Khởi tạo cấu trúc dự án.
